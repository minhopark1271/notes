## 배경 및 동기

[Backlog-Reclassification-And-Status](Backlog-Reclassification-And-Status.md) 2절의 35건 중 **완료 6건(B4·D5·E3·E4·E5·F3)과 진행 중인 F4 를 뺀 28건**을 [refactoring (#16)](https://github.com/orgs/NumeRealWorks/projects/16) 에 이슈로 발행한다. 덩어리가 큰 13건은 서브이슈로 분해한다.

발행 전에 두 가지가 필요했다.

- **중복 판정** — 열린 이슈·닫힌 이슈 전량과 대조. 28건 중 상당수가 이미 이슈로 존재하거나 이미 닫혀 있다
- **B1 서브목록 재도출** — 원안의 B1 서브가 B7 의 것과 같은 내용이었다 (붙여넣기 착오). 재도출해 발행 목록에 반영했다

**결정 — W10 체인 폐기는 작업 정의·상세 계획의 폐기다.** 내용은 본 문서에 수정해 남겼고 항목 재정의로 덮어쓸 예정이므로, 폐기된 티켓 번호 참조는 본 문서에서 끊는다.

## 1. 발행 규칙

### 1-1. Priority 매핑

원 우선순위 1·2 → `High` · 3 → `Medium` · 4·5 → `Low`.

### 1-2. 제목·본문 분리

항목 정의는 `제목 — 부연 > 해결` 형태다. `—` 앞까지를 제목으로, 뒤를 본문 첫 줄로 옮긴다.

```
제목: 파일 쓰기 원자성
본문: 쓰기 중 크래시/디스크 풀 시 JSON 0바이트·반토막 파손.
      A1 헬퍼에 QSaveFile 경유 내장.
```

코드(`A6a`·`C1b` 등)는 제목에 쓰지 않는다. 문서 내 코드 상호 참조는 발행 시 그 이슈 번호로 전량 치환하고, 코드 체계는 폐기한다.

### 1-3. 판정·태그 범례

**판정** — 기존 이슈와의 관계.

| 판정 | 뜻 | 조치 |
|---|---|---|
| **신규** | 겹치는 이슈 없음 | 발행 |
| **부분** | 기존 이슈가 일부만 덮음 | 범위를 좁혀 발행 + 기존 이슈 링크 |
| **중복** | 열린 기존 이슈와 같은 범위 | 발행 금지 — 기존 번호를 쓴다 |
| **완료** | 기존 이슈가 `completed` 로 닫힘 | 발행 금지 |
| **이관** | 같은 작업이 다른 코드 아래로 옮겨짐 | 발행 금지 — 이관처에서 1회 발행 |

**태그** — 행별 세부. 접점(덮지 않는 인접 이슈)은 `접점:#N`, 선후 조건은 `선행:`/`후행:`/`하드선행:` 으로 적는다.

| 태그 | 뜻 |
|---|---|
| `발행금지` | 중복·완료·이관의 귀결 |
| `범위축소` · `규칙만발행` | 부분 발행의 형태 |
| `이관→X` · `흡수→#N` | 작업이 넘어가는 곳 |
| `주N` | 3절 미주 |
