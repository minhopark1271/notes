## 목적

DOE Sampler의 Add Set을 복원하되 Resample만 추가할 수 있게 한다. Init은 1개로 고정하고 Resample은 번호가 붙는다: `Init`, `Resample1`, `Resample2`, …

## 범위

- Add Set 메뉴: Init은 이미 있으면 비활성화, Resample은 항상 활성. 새 Resample 이름은 비어 있는 번호 중 가장 작은 `ResampleN`.
- Add Set을 누르면 "Resample Set이 추가됩니다" 안내 팝업을 띄운다.
- Rename은 계속 불가.
- Resample Set의 Reference Set 콤보 기본값은 직전 Set(`Resample(N-1)`, N=1이면 `Init`). 사용자가 콤보에서 바꿀 수 있다.
- Analysis Launcher가 쓰는 DOE Table은 번호가 가장 큰 `ResampleN`, 없으면 `Init`.

- Resample의 이전 이력(prior)에서 비활성 케이스를 빼는 규칙: #601 이후 `active`는 DOE Sampler json이 아니라 `AnalysisLauncher_<Set>.json`의 `Launcher Cases`에 있다. `collectReferencePoints`가 이를 읽도록 바꾼다 (`// TODO(#615)` 표시).

## 범위 밖
