## 대상

Analysis Launcher(구 Data Preprocessor)의 Preprocess XML 작성과, 그 XML을 읽는 Model Builder·Analysis Launcher의 파서.

## 현재

응답(response)마다 XML을 하나씩 만든다. 같은 컴포넌트에 응답이 여러 개면 node location·connectivity·design variable이 파일마다 중복 기록되어 파일이 커진다.

## 1차

Analysis Launcher Set이 Reference File 하나를 대상으로 하므로(#603) XML도 Set 단위로 하나를 쓴다. 응답은 그 파일 안에 추가한다.

## 2차

XML이 Set의 uuid(`referenceModel.uuid`, DOE `tableId`)를 확인하고 이어쓰기·덮어쓰기를 선택한다. XML이 이 작업에 맞지 않으면 HDF5 전환을 검토한다.

## 추가 고려

1. Target part가 하나가 아닌 경우가 생길 수 있다. 개발 중인 Builder 기능에 여러 part를 한 파일에 저장하는 포맷이 있으므로 그것과 비교·검토해 호환되게 맞춘다.
2. Morphing은 N개 케이스의 node index·connectivity가 모두 같다. 이를 구분하는 정보를 두고 중복 정보는 한 번만 저장한다.
3. HDF5로 가면 Builder·Analysis Launcher의 XML 파싱(`DashXmlParser`, 캐시 #515)도 함께 전환한다.
