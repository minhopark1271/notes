## 목적

#603·#633에서 Analysis Launcher Set에만 넣은 두 장치를 파이프라인 전체 모듈로 확장한다.

- **참조 Set 핀**: Set이 어느 상류 산출물을 쓰는지 id로 기록한다 (지금은 `referenceModel {uuid, path}`와 DOE Table `tableId` 스냅샷).
- **버전 불일치 경고**: 상류 산출물이 다시 생성돼 id가 바뀌면 Module Tree의 Set 이름 옆에 ⚠를 표시한다 (지금은 DOE Sampler → Analysis Launcher 한 쌍만).

## 범위

| 하류 Set | 기록할 상류 id | 비고 |
|---|---|---|
| Model Builder | Analysis Launcher Set의 Preprocess XML id | XML Set 단위화(#643)와 함께 |
| Model Runner | Model Builder Set의 모델 id | |
| Optimizer | Model Builder Set의 모델 id, Condition·Geometry Set | |
| Results Analyzer | 읽는 Set들의 id | 표시만 |
| DOE Sampler | Geometry·Condition Set (조합 기록 D21은 이미 있음) | ⚠ 표시만 추가 |

- 검사는 `DashProject::refreshUpstreamStaleness()` 한 곳에 쌍을 추가하는 구조를 유지한다.
- 갱신 시점: 프로젝트 열 때, 각 모듈 Run 완료, Set 선택.
