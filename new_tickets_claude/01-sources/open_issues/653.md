## 목적

Model Runner와 Optimizer에 FE Validation 버튼을 둔다. 해당 Set에서 확인할 수 있는 입력 파일과 Target Part를 Direct Launch 다이얼로그(#604)에 채워 띄우고, 실행이 끝나면 Result Preview로 결과를 확인한다. 입력 파일 생성은 별도 버튼의 몫이며 이 이슈 범위가 아니다.

## 범위

- Model Runner·Optimizer 화면에 FE Validation 버튼 추가. 누르면 Direct Launch 다이얼로그를 열고 그 Set의 입력 파일·Target Part·출력 폴더를 채운다.
- 다이얼로그에 `prefill(inputPath, targetPart, outputFolder)` 진입점 추가. 호출 시 창을 열고 Launcher 페이지로 이동.
- 출력 폴더 기본값은 호출한 Set의 모듈 폴더 아래 `FEValidation/`.
- Done 뒤 Result Preview 자동 선택, Direct↔Analysis Launcher 상호 배제는 #604 동작 그대로.

## 범위 밖

- 입력 파일(inp) 생성 — 별도 버튼
- Set 설정(target file·응답·KPI)으로 결과를 처리하는 단계 — 결과 리더·처리기 분리(#433) 뒤에 검토
