## 현상

- Launcher에서 Re-run으로 다시 실행한 뒤 Preprocess 탭의 부품·하중 목록이 이전 결과 기준으로 남아 있다.
- Re-run을 고르면 기존 결과를 먼저 지우고 실행하므로, 실행이 실패하면 이전 결과까지 잃는다.
- Start 확인창의 Skip이 "결과가 있는 케이스는 건너뛴다"는 뜻임을 화면에서 알 수 없다.

## 원인

Preprocess 탭은 Set 선택 시점에만 입력을 다시 찾는다. Re-run은 `clearCaseResults` 뒤 실행하는 순서라 실패 시 복구할 사본이 없다. Skip 버튼에 설명이 없다.

## 기대

- 실행이 끝나면 Preprocess 탭이 새 `resultFiles` 기준으로 목록을 다시 채운다.
- Re-run은 새 결과가 Done이 된 뒤에 이전 결과를 정리하거나, 실패 시 이전 상태로 되돌린다.
- Skip의 의미를 확인창 본문이나 툴팁으로 알린다.
