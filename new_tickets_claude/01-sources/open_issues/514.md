## Goal

표에 셀 위젯을 올리는 모든 지점에서 행 번호를 캡처하지 않고 호출 시점에 해석한다. 잔여 오작동 4건과 잠복 1건을 제거하고 행 해석 규칙을 공용 헬퍼 하나로 통일한다.

## Background

#419 (제약 행) 와 #503 (physics 파일 표) 은 같은 결함이었다 — 위젯 생성 시점의 행 번호를 람다에 캡처해 두고, 그 위에서 행이 삭제되면 캡처값이 밀린다. 두 번 반복된 결함이라 정수형 인덱스를 캡처하는 람다 26곳을 전수조사했고, 개별 행 삭제 경로가 있는 표에서 5건이 더 나왔다.

## Design

### 대안 비교

| 방안 | 핵심 | 평가 |
|---|---|---|
| A. 파일별 private 헬퍼 복제 | `physicsRowOfWidget` 을 5개 클래스에 추가 | 복제가 결함의 원인인데 같은 처방을 반복 |
| B. `indexAt(중심점)` 통일 | 위젯 좌표로 행 조회 | 대상 5곳 중 3곳에서 성립 불가 (아래) |
| **C. 공용 자유 함수** | `DashWidgetHelpers` 에 1개 | **채택** |

**선택 근거**: 결함이 세 번 반복된 원인이 규칙의 분산이다. 또한 교정 대상 5곳 중 **3곳(2·3·4번)은 캡처 위젯이 셀 위젯이 아니라 그 자손**이다 — browse 버튼이 `QHBoxLayout` 컨테이너 안에 있고 컨테이너가 셀 위젯으로 등록된다. 그래서 B 는 `pos()` 가 부모 기준이라 어긋나고, A 는 자손 탐색 보정을 5곳에 각각 넣어야 한다. `DashWidgetHelpers` 는 이미 `createCenteredCell` 로 셀 위젯 생성 규칙을 담고 있어 해석 규칙의 자리로도 정합하다.

```cpp
// view/common/DashWidgetHelpers.h

// widget 이 놓인 현재 행. widget 은 셀 위젯 자신이거나 그 자손이어도 된다.
// 행 번호를 캡처하면 removeRow 뒤 밀리므로 호출 시점에 이 함수로 해석한다.
// 못 찾으면 -1 — 호출측은 부수효과 이전에 멈춘다.
int tableRowOfCellWidget(const QTableWidget* table, const QWidget* widget);
```
