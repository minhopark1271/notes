## 보드 스냅샷 밖 후속과 현재 정책

#685는 이 62행 원본 밖 후속 이슈이며 [PRJ-04](03_TASK_CATALOG.md#prj-04)에 연결한다. #368의 생산 계약 이후 Runner·Optimizer가 Builder 참조를 저장·복원하고 출처를 검증해 실행·조회·프리뷰에 사용한다. #369는 #443에서 분리된 독립 RUN-04다.

상류 참조를 다른 `setId`로 바꿀 수 있고 현재 Set ID는 유지한다. 선택 변경만으로 산출물 출처를 수정하지 않으며 재실행 덮어쓰기 때 실제 입력 출처를 함께 갱신한다. 전체 과거 이력 보존은 요구하지 않는다. 필수 출처 없는 구산출물은 재생성하며 이름·경로 추론·자동 이관을 하지 않고 기존 Set ID 복원은 유지한다.
