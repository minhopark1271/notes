# #601 Analysis Launcher: DOE Launcher 탭을 첫 탭으로 이관하고 Data Upload 탭을 제거한다

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/601
- Board status: Done
- Labels: ['feature', 'refactor']

## 목적

DOE Sampler의 DOE Launcher 탭을 Analysis Launcher(구 Data Preprocessor)의 첫 번째 탭 "Launcher"로 옮기고, Data Upload 탭을 없앤다.

## 범위

- Launcher 탭과 해석 실행 책임을 새 모듈로 이관. Set이 Reference File 하나에 묶이므로(#603) Reference File 표는 없애고 Target Part 콤보, Material 버튼(기존 위치), CPU, Start/Stop, Output Cases만 둔다.
- Launcher는 번호가 가장 큰 `ResampleN`, 없으면 `Init`의 DOE Table을 사용한다(#615).
- 결과 폴더는 `AnalysisLauncher_<파일명>/<DOE Sampler Set>/runsN`. Resample에 포함된 Init 케이스(prior)는 완료 상태면 읽기 전용으로 표시한다.
- 실행 상태·결과는 새 모듈 설정 파일과 폴더에 저장하고, 결과 폴더는 DOE Sampler Set별로 나눈다.
- DOE Sampler 설정 파일에서 `DOE Table.input`·`DOE Table.output` 쓰기 제거
- Data Upload 탭(단일 파일 임포트 포함)과 `Dataset` 키 쓰기 제거
- Preprocess 탭은 해석 타입을 고르지 않고 Set의 파일에 대해 Launcher의 Output Cases(Done, prior 포함)로 결과 파일을 찾는다.
