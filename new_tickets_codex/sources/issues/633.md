# #633 Module Tree: 상류 DOE Table id가 바뀐 Analysis Launcher Set에 경고 아이콘을 표시한다

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/633
- Board status: Done
- Labels: ['feature', 'refactor']

## 목적

상류 Set의 산출물이 바뀌어 하류 Set이 기록해 둔 식별자와 맞지 않을 때, Module Tree의 Set 이름 오른쪽에 경고 아이콘을 표시한다. 1차 범위는 Analysis Launcher Set ↔ DOE Table이다.

## 범위

- Analysis Launcher Set json의 스냅샷 `DOE Table.<DoeSet>.tableId`와 현재 `DoeSampler_<DoeSet>.json`의 `tableId`를 비교한다. 다르면 Module Tree의 해당 Set 이름 뒤에 ⚠ 표시와 툴팁("DOE Table(Init)이 Launcher 실행 이후 다시 생성됨")을 붙인다.
- 갱신 시점: 프로젝트 열 때, DOE Sampler Run 완료 시, Launcher Start로 스냅샷을 새로 찍었을 때(표시 해제).
- 검사 로직은 `DashProject`에 "Set별 상류 불일치 검사" 한 곳으로 두고, 지금은 Analysis Launcher ↔ DOE Sampler 쌍만 등록한다.

## 범위 밖

- Model Builder ↔ Analysis Launcher XML, Optimizer ↔ Builder 모델 등 다른 쌍 (같은 자리에 추가 예정)
- Launcher 탭 헤더의 "DOE Table changed since last launch" 힌트(#601에서 구현됨)와는 별개로 Module Tree에서 보이는 표시
