# #568 Data Upload 결과 표 구성 실패 시 로딩 스피너가 꺼지지 않는다 — onAnalysisFileSelected 오류 반환 4곳이 endProcessing() 누락

- Labels: ['bugfix', 'refactor']

## 현상
해석 결과 파일이 아직 없는 analysis type 을 Data Upload 에서 고르면(해석 진행 중·실패), 오류 팝업을 닫아도 스피너와 상태바 "Building result table..." 이 남는다. 그 Set 에서는 재시작 전까지 꺼지지 않아 프리징으로 보인다.

## 원인
`model/DashDataProcessor.cpp` `onAnalysisFileSelected` — `:335` `beginProcessing()` 뒤의 오류 반환 `:394` · `:423` · `:458` · `:600` 이 `endProcessing()` 을 건너뛴다. 깊이 카운터(`:2864-2876`)가 1 로 남아 이후 `processingStarted` / `processingFinished` 가 다시 나가지 않는다. 앞쪽 가드 4곳(`:343-370`)은 부른다. `53b7737`(2026-04-17, 인디케이터 도입) 부터 빠져 있었다.

analysis type 콤보는 `runs\d+` 폴더가 있는 디렉터리만 나열하므로(`:245-256`) 실제로 닿는 것은 `:458`(결과 파일 없음) 과 `:600`(지원 확장자 없음) 이다.

## 기대
네 반환 지점이 `endProcessing()` 을 거친다. 4줄. 스캐너 추출(#569)이 먼저 들어가면 반환 지점이 한 곳으로 모여 1줄.
