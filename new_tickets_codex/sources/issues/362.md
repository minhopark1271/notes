# #362 G3 렌더 커서 개명 active* → displayed* (T5)

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/362

- Labels: ['refactor', 'split-group:360']

## Original Request
> Project-Manifest-4-Ticket-Slicing.md 기반으로 issue 생성

## Goal
렌더 커서의 API 이름이 역할을 말한다 — `active*` 가 전부 `displayed*` 로 바뀌고 동작 변화는 0 이다.

## Background
> source: wiki [Project-Manifest-4-Ticket-Slicing](https://github.com/NumeRealWorks/DashOpti_GUI/wiki/Project-Manifest-4-Ticket-Slicing) "PR 상세" G3 절

`active*` 는 커서가 두 역할을 겸하던 시절의 이름이다. G1·G2 를 거친 이 시점에 `active*` 의 소비자가 렌더뿐이라 `displayed*` 가 참이 된다 — S5(개명은 소비자 이동 뒤에)가 요구하는 순서다. `render*` 는 그래픽스에서 render target 이 프레임버퍼를 뜻해 배제, `visible*` 은 `controlVisibility()` 의 파트 단위 가시성과 겹쳐 배제했다 (D1).

## Technical Details

### as-is
- 커서 API 이름이 `active*` — 멤버 `m_activeFilePath`·`m_activeActor`, 세터 `setActiveContext`, 접근자 `activeContext`/`activeFilePath`/`activeAbsolutePath`/`activeActor`, 시그널 `activeContextChanged`/`activeActorUpdated`
- API 등장 59줄·토큰 67건 / 9 파일 (`c989257` word-boundary 전수 grep 재실측 · `DashOcctViewWidget` 오탐 제외 · `activeAbsolutePath` 는 G2 신설이라 현시점 0건)

### to-be
- `m_activeFilePath`·`m_activeActor` → `m_displayedFilePath`·`m_displayedActor`
- `setActiveContext` → `setDisplayedContext`
- `activeContext`/`activeFilePath`/`activeAbsolutePath`/`activeActor` → `displayed*`
- `activeContextChanged`/`activeActorUpdated` → `displayed*`

### not-to-be
- `DashOcctViewWidget` 의 `m_context`·`AIS_InteractiveContext` — 이름만 비슷한 남이다. 대상 아님
- 기준모델 계열 이름 — `referenceFilePath()`·`Registry::clear` 처럼 처음부터 새 이름이라 개명 대상이 아니다
- rename 외의 변경 — diff 에 섞이면 반려
