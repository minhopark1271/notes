# #590 원형도 계산: 대상 부품 누락 시 샘플 제외

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/590
- Board status: Done
- Labels: ['in-progress', 'bugfix', 'refactor']

원형도 계산에서 일부 BORE/BOSS 부품의 변위가 누락되어도 나머지 부품만으로 `max_circularity`를 저장합니다. 전체 대상의 최댓값을 보장하지 못합니다.

필요한 부품의 변위를 모두 읽은 샘플만 저장합니다. 일부 부품이 누락되면 해당 샘플 전체를 제외하고, 정상 샘플과 후속 요청은 계속 처리합니다. 원형도 계산식과 XML 형식은 유지합니다.

완료 기준:

- [x] 대상 BORE/BOSS 부품이 모두 정상인 경우 기존 원형도를 저장한다.
- [x] 일부 부품의 응답·벡터가 없거나 데이터가 비어 있으면 해당 샘플을 제외한다.
- [x] 실제 읽기 장애는 `ReadFailed`, 응답 누락은 `Missing`으로 구분한다.
- [x] 실패 샘플의 파라미터·형상·필드가 XML에 남지 않으며 후속 샘플을 처리한다.
- [x] 재현 테스트와 Level 1 테스트가 통과하고 Release 앱 빌드 오류가 0이다.
- [x] 새 세션에서 변경 범위·시나리오·컨벤션·불필요한 기능·컨셉 이탈을 검토한다.
