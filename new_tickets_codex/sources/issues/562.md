# #562 Set Rename 시 산출물 폴더·vtp 사이드카·Launcher Selected Design Variables 가 옛 이름에 남는다 — renameSet 이 모듈 json 1개만 개명

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/562
- Board status: Backlog
- Labels: ['bug', 'source:QC']

## 현상

Set 을 Rename 하면 configs 의 `{Module}_{Set}.json` 1개만 새 이름으로 바뀌고, 그 Set 을 가리키는 나머지 디스크 흔적은 전부 옛 이름에 남는다.

1. **산출물 폴더** `{projectRoot}/{Module}_{Set}/` 이 개명되지 않는다. 옛 폴더는 고아로 남고 다음 Run 때 새 이름 폴더가 빈 채로 생겨 기존 run 결과가 새 Set 에서 보이지 않는다.
2. **GeometryParameter 의 `.vtp` 사이드카**가 개명되지 않는다. json 은 `GeometryParameter_New.json`, vtp 는 `GeometryParameter_Old.vtp` 로 어긋나고, 다음 저장 때 새 vtp 가 하나 더 생겨 옛 vtp 가 고아로 남는다.
3. **AnalysisLauncher json 의 `DOE configuration > Selected Design Variables`** 가 옛 Set 이름을 유지한다. DOE/모핑이 `GeometryParameter_{옛이름}.json` 을 찾지 못해 실패하고, `refreshParameterization` 의 setId 조회도 미스가 나 이후 기록되는 조합이 이름 전용 형태로 퇴화한다.
4. (부수) `-CAD` Geometry Set 은 Rename 이 반쪽만 된다. 디스크 json 은 새 이름으로 바뀌는데 모델 갱신이 실패해 UI 가 옛 이름으로 되돌아가, 디스크와 모델이 어긋난다.

## 원인

`DashProject::renameSet()` (`model/DashProject.cpp:1492`) 이 디스크에 하는 유일한 작업이 모듈 json 1개 `QFile::rename` 이고, Rename 시그널도 발행하지 않는다. 

- 1: 폴더명은 `DashIOController::getModuleDir()` 이 `{Module}_{setName}` 으로 조립하고 실행 시점에 lazy 생성된다. renameSet 에 `QDir::rename` 이 없다.
- 2: vtp 파일명이 json 베이스명에서 파생된다 (`viewmodel/DashGeometryParameterPresentationModel.cpp:340`). renameSet 은 같은 stem 의 사이드카를 대상으로 삼지 않는다.
- 3: `DashDoeSelection::writeSelectedSets()` (`model/DashDoeSelection.cpp:122`) 가 `{"set": "<이름>"}` 만 기록하고 setId 가 없다. #533 의 setId 조인 전환은 `parameterization`·`DOE Table.columns` 만 다뤘고 이 키는 범위 밖이라 남은 누락분이다. 소비자 5곳(`DashMorphingDoeExecutor.cpp:127`, `DashJobRunner.cpp:2329`, `DashDoeConfigManager.cpp:67`, `DashDataProcessor.cpp:3007`, `DashAnalysisLauncher.cpp:1551`)이 이름으로 파일명을 조립한다.
- 4: renameSet 의 Geometry 분기가 `m_geometryParameters` 만 순회하고 `m_geometryParametersCAD` 를 빠뜨린다 (`model/DashProject.cpp:1531`). `deleteSet` 은 `-CAD` 분기가 있어 비대칭.

## 기대

- Rename 이 산출물 폴더·vtp 사이드카(및 json 안 `handles_vtp`)를 동반 개명한다. 폴더 개명 실패 시 json 개명을 롤백하거나 잡 실행 중에는 Rename 을 거부한다 (wiki SI-6a 성립 조건 ①).
- `Selected Design Variables` 가 `columns` 와 같은 규약(setId 기록 + name 병기, SI-4)으로 전환되어 Rename 뒤에도 조인이 유지된다.
- `-CAD` Set Rename 이 deleteSet 과 같은 분기로 모델까지 갱신된다.
