## PR #515 (`038e687`) 측정에서 나온 재료

XML 파싱 축(#413)이 끝난 뒤에도 **진행 표시 없이 멈추는 구간이 남는다.**

- 첫 플롯 1회에서 `parse 12,255 ms` + `load 12,310 ms` 동안 GUI 가 멈추고, 그동안 사용자에게 아무 표시가 없다 (4.1GB 파일 기준).
- 이후 플롯은 캐시 히트로 `load 0 ms` 라 표시가 필요 없다.

즉 이 티켓이 덮어야 할 구간이 **"조작마다"에서 "파일당 첫 1회"로 줄었다.** 표시 대상이 명확해진 만큼 범위도 작아진다.

이슈 본문은 수정하지 않았다.
