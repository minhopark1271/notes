# #584 MVVM 도입 — Model·ViewModel 공통 기반과 규칙 문서

https://github.com/NumeRealWorks/DashOpti_GUI/issues/584

## 목적

Qt 6 의 `QProperty` 바인딩을 쓰는 MVVM 구조를 도입한다. 첫 단계로 Model·ViewModel 공통 기반과 규칙 문서를 저장소에 넣는다.

## 범위

- `model/DashMvvmModelBase.h`: Model 공통 기반 (헤더 전용 템플릿, QObject 아님). `valid`·`snapshot`·`save`·`load` 공통 구현.
- `viewmodel/DashMvvmViewModelBase.h/.cpp`: ViewModel 공통 기반 (`valid` 와 `validChanged`).
- `tests/`: PoC 의 자가 검증을 ctest 테스트로 옮긴다. 예시 Model/ViewModel 은 테스트 픽스처로만 둔다.
- `docs/`: 에이전트와 사람이 따를 MVVM 규칙 문서. 초안으로 넣고 첫 적용 작업에서 다듬는다.
- 직렬화는 기존 `utils/DashGadgetCodec` 을 쓴다.

## 범위 밖

- 기존 `viewmodel/` PresentationModel 들의 이관.
- 필드 목록을 생성하는 코드 생성기.
