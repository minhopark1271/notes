## 목적

Geometry Parameter와 DOE Sampler의 Set명을 고정 목록으로 제한하고 중복 생성을 막는다.

## 범위

- Geometry Parameter: Morphing / CAD, DOE Sampler: Init / Resample 만 생성. 같은 이름이 있으면 생성하지 않는다.
- Add Set 메뉴에서 Direct Launch 제거
- 두 모듈의 Rename 메뉴 숨김
- Set 종류 판별을 이름 접미어가 아니라 설정 파일의 variant 값으로 바꾼다.
- DOE Sampler Set 선택을 행 번호가 아니라 이름으로 매칭한다. Geometry 쪽은 #588에서 처리한다.
- Set명이 비었을 때 쓰는 "Set1" 기본값 점검

## 범위 밖

- 기존 프로젝트의 Set명 변환 (신규 Set에만 적용)
