**PR #654 의 상태기가 이 이슈의 `DashHandleData` 를 대체한다.**

핸들·마커·DV 의 정본이 `DashHandleSetup` / `DashHandleConfiguration` 값 타입이 되고, 영속은 `Morphing.handles` JSON 하나(`version: 1`)다. 핸들 VTP 쓰기(`DashStateSnapshot` 사이드카 · PresentationModel)와 `constraints[]` 쓰기는 그 PR 에서 사라지고, `DashHandleCloud` 의 VTP 읽기(`mapDvGeometry` · `initialPoints` · `targetPoints`)도 삭제된다. 즉 이 이슈가 세던 "읽기 5곳·쓰기 2곳" 은 일원화가 아니라 소멸한다.

남는 것은 interaction 이 아직 들고 있는 `m_handleGeometry` 폴리데이터다. PR 2 에서 set 의 `output_port()` 에 렌더가 붙고 그 폴리데이터가 `projection()` 캐시가 되면 이 이슈를 닫는다.
