# #523 Data Preprocessor: AnsysMotion .dfr 단일 파일 import 시 결과가 렌더링되지 않음

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/523
- Board status: Done
- Labels: ['bug', 'source:QC']

## 현상
Data Preprocessor > Data Upload에서 `Import single file ...`로 `.dfr` 파일 하나를 추가하고 `Load Raw Dataset`을 누르면 Mesh View에 아무것도 그려지지 않는다. 로그에 `JSON PARSE ERROR (TimeSteps/Geometries): illegal value`, `GetGeometryVtk: invalid query or input index` 경고가 뜬다. 같은 경로로 Ansys `.rst`를 넣으면 정상 동작한다.

## 원인
GUI는 `.dfr` 확장자로 AnsysMotion 플러그인을 정상 선택하고 워커 태스크도 `ansys_motion`으로 ready 상태까지 생성된다(`WorkerTask.cpp:154`, 환경 `ANSYS Student/v261`, `Motion/bin` 존재 확인). 그 뒤 `GetTimeSteps`/`GetGeometries`가 실패 Result를 돌려 `LegacyJsonPreprocessor::Times()/Domains()`가 nullptr을 반환하고 위 세 경고가 연쇄된다. 즉 AnsysMotion 워커가 단독 `.dfr` 파일 열거에 실패하는 것으로, 원인은 DashOpti_Preprocessor의 AnsysMotion 리더 쪽이다 (추정: 워커 ready 이후 실패 로그로 확정 필요. `.dfsxml` 모델 파일 동반이 필요한 형식이라면 단일 파일 다이얼로그 `view/DashDataProcessorWidget.cpp:544`가 `.dfr` 하나만 등록하는 것이 문제).

## 기대
`.dfr` 단일 파일도 DOE JSON 없이 `.rst`와 동일하게 로드되어 Mesh View에 지오메트리와 결과 필드가 표시된다.
