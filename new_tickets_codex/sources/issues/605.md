# #605 모핑 상태 이관 완결 — DashManager 협력자 등록·시그널 정리와 DOE 실행 facade 이탈

## 목적

#588(#221 진입 계약)이 모핑 기하·프리뷰 상태와 소비자 주입을 `DashGeometryParameterWidget`으로 옮긴 뒤 `DashManager`에 남은 모핑 몫을 지운다. #434 4단계 「모핑 상태 이관」의 마지막 조각이다.

## 배경 (#588 이후 실측)

- 소비자의 `Mgr()` 모핑 재조회는 MainWindow 배선 1곳(`GetHandlePickingInteraction`/`GetHandleVisualizer`)만 남았다.
- `DashManager`에는 이제 **쓰기 전용**이 된 협력자 등록(`Set/GetGeometryParameterWidget` · `setMorphingController` · `Set/GetMorphingSettingsWidget`), 시그널 2종(`ResetMorphingBar` · `CloseMorphingSetting`)과 emit 헬퍼 `InteractionModeReset`, 사용처 없는 `m_lut`/`GetLUT`, DOE 배치 facade `MorphFromDoeSamples`가 남아 있다.

## 구현 범위

- [ ] interaction의 MODE_CONFIG 진입 통지를 `DashManager` 시그널 대신 `DashPreviewHost`로 보낸다. 위젯이 시그널로 fan-out하고 MainWindow가 `DashMorphingBar` 리셋·`DashMorphingSettings` 숨김을 직접 connect한다. Manager의 시그널 2종과 `InteractionModeReset`을 삭제한다.
- [ ] 쓰기 전용 협력자 멤버·등록 API 삭제(`m_geometryParameterWidget` · `morphingController_` · `m_morphingSettingsWidget`).
- [ ] `m_lut` · `GetLUT` 삭제(렌더 LUT는 `DashRenderingManager` 소유).
- [ ] `MorphFromDoeSamples`를 `DashMorphingDoeExecutor` 옆 자유 코루틴으로 옮긴다(registry 덱 로드와 refuse 매핑 포함, master plan 결정 ④). `DashJobRunner` · `DashJobRunnerAnsysMotion` 호출부 치환, Manager의 `DashDoeBatchChain` 의존 제거.

## 완료 기준

- `DashManager.h`의 모핑 몫이 `m_handlePicking` · `m_handleVisualizer` · 두 Get 접근자만 남는다(소유 이동은 #434 2단계 몫).
- grep 0건: `MorphFromDoeSamples` · `ResetMorphingBar|CloseMorphingSetting|InteractionModeReset` · 협력자 등록 API.
- Level 2 테스트 통과, Release 앱 빌드.
