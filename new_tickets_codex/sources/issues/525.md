# #525 Morphing: Geometry Parameterization 세트를 열지 않은 세션에서 DOE 모핑이 핸들을 복원하지 못해 전 샘플 실패

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/525
- Board status: Done
- Labels: ['bug', 'source:QC']

## 현상
프로젝트를 열고 Geometry Parameterization 세트를 한 번도 열지 않은 상태로 Analysis Launcher를 Start하면 모든 샘플이 `Missing currentHandles or ug` WARN으로 실패하고 해석 입력이 생성되지 않는다. 프로젝트 트리의 Load 버튼으로 참조 .dat를 뷰에 올려도 동일하다.

## 원인
`DashMorphingDoeExecutor::loadHandlesFromVtp`(`controller/DashMorphingDoeExecutor.cpp:1060`)가 VTP를 읽은 뒤 `interaction->GetMorphingHandles()`가 null이면 복사를 건너뛰고 로그 없이 반환한다. 이 핸들 polydata는 `DashManager::SetInputVTU`(`controller/DashManager.cpp:318`)에서만 생성되고, 그 호출은 Geometry Parameterization 세트를 열 때의 `UpdateTargetGeometry`(`view/DashGeometryParameterWidget.cpp:1972`) 한 곳뿐이다. 트리의 Load 버튼은 메시 액터만 올리므로 해당하지 않는다.

## 기대
DOE 모핑이 Geometry Parameterization 모듈을 열었는지와 무관하게 VTP 핸들을 복원해 실행된다. 핸들 복원에 실패하면 샘플 루프 진입 전에 ERROR와 함께 즉시 중단된다.
