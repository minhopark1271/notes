## 무엇

#500 의 선택지 1 로 `DashMorphingDoeExecutor::Execute` 가 배치 시작 전에 Launcher 의 Target Component(`batchPart`)와 GP 세트의 part(GeometryParameter JSON 의 `DV-Geometry` `source`, `DashDoeSelection::morphingPartName`)를 비교한다. 다르면 첫 샘플 전에 배치 전체가 Failed 다.

`source` 가 없는 옛 세트는 비교할 대상이 없다. 지금은 **WARN 을 남기고 Target Component 가 편집 가능한 part 인지만 검사한 뒤 진행**한다. 코드에 `TODO(#500)` 로 적혀 있다.

## 결정할 것

- 옛 세트를 하드 실패시킬 것인가(세트를 다시 저장하게 유도), 아니면 지금처럼 진행할 것인가.
- 진행이라면 `source` 를 채우는 마이그레이션이 있는가(`DashSetLegacyMigration` 계열).

한 줄짜리 변경이다. 결정만 필요하다.
