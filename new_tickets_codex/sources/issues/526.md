## 현상
> 2026-09-21 결정 개정(D15 재개정 · D28 폐기 · D16 3차 개정)의 G7 기반영분 정정 — 처분 문서 "이슈·구현" 표의 신규 발행분

G7(#472 — dev 반영 #507)의 `referenceModel` backfill 이 구프로젝트 Set 진입 시 **전역 reference** 를 핀한다. 첫 진입 시점의 우연(다른 deck Load 상태)이 영구 동결되고 D17(변경 UI 불요)로 정정 경로가 없다 — 정정 전 dev 로 구프로젝트를 열 때마다 오핀 코호트가 누적된다(지연 = 손실).

## 범위
- 건드림: `DashSetReferenceModel` 의 backfill·해석 트리 · `DashDesignVariableModel` 의 D28 기계장치 · multi-source json 마이그레이션
- 안 건드림: G7 기반영분의 이력·티켓 본문(T15·T16) — 구현 시점 기록으로 불변, 소급 수정 없음 · setId 도입 — G11(#520) 소유

## 현재 구조
- backfill(키 부재 시): 진입 1회 전역 reference 를 읽어 핀 + 다음 저장 write-back (T16 — D15 종전)
- multi-source Condition json: 핀 deck 밖 `source` 행을 읽기 전용 보존 — 회색·잠금·툴팁(`DashDesignVariableModel`) + `loadFromJsons` 핀 deck 인자 + `FECondition` 예외 판정 + DOE 의 구 multi-source 읽기 경로 (D28 종전)
- `referenceModel` 해석: uuid 직조회 → 미스면 path 원장 스캔(히트 시 uuid backfill) → 실패 시 미지정 + 로그 (D16 2차)

## 문제
- 전역 출처 backfill 은 G7 이 닫은 대표 결함(전역-화면 결합)을 마이그레이션 코호트에서 1회 재현한 채 영구화한다 — Set 자신의 DV `source` 가 더 충실한 역사적 증거다
- D28 은 다중 deck 메커니즘 두 벌(D27 다중 선택과)의 영구 공존 — 하위호환용 상시 기계장치
- D16 의 스캔 분기는 uuid ≡ v5(상대경로)인 동안 발화 조건이 없다 — "원장 유실 한정" 명분은 유실된 원장을 스캔할 수 없어 자기모순

## 변경
정본은 [처분 문서](https://github.com/NumeRealWorks/DashOpti_GUI/wiki/Project-Manifest-Set-Identity-And-Decision-Revisions) D15 재개정 · D28 폐기 · D16 3차 개정.

- **T30 — D15 재개정 + D28 기계장치 제거**: backfill 핀 출처를 전역에서 **Set 자신의 DV `source` 유도**로 — Condition 은 상대경로 그대로, Morphing 은 bare filename 을 configs 복사본 → 원장 `path` → 루트 스캔 순 해석(복수 히트는 정렬 후 첫번째 + 로그). 유도 실패 시에만 전역 폴백, 빈 값이면 핀 안 함, 소급 없음(기존 핀 불문). **multi-source json 은 진입 시 1회 자동 분할**(deck 별 Set) + `.bak` 보존 + 결과 통지(선택지 없음). D28 기계장치 4종 제거 — 회색·잠금·툴팁, `loadFromJsons` 핀 deck 인자, `FECondition` 예외 판정, DOE 구 multi-source 읽기 경로. 분할이 제거의 전제라 한 티켓
- **T31 — D16 3차 개정**: 해석 2단(path 원장 스캔 + uuid backfill)을 **v5(path) 재파생 조회 1회**로 교체. D11 의 "두 값 갈림 → 원장 정본 backfill" 은 후속작업 4(sha256 이관) 전까지 유보

## 기대
- 구프로젝트 Set 진입 → 자기 DV `source` 의 deck 이 핀된다(전역 상태 무관) · 유도 실패 케이스만 전역 폴백
- multi-source json 진입 → deck 별 Set 자동 분할 + `.bak` + 통지, 분할 후 어느 Set 에도 foreign 행 없음
- `path` 를 원장에 없는 값으로 손편집 → 미지정 + 로그 · 그 deck 재Load 후 재진입 시 회복(v5 재파생이 재생 uuid 에 히트)
