구 P5(VTU/VTK·CSV 쓰기 워커화)의 대상 5곳을 전수 판정해 **실작업이 dead code 2곳 삭제(183줄)뿐임을 확정하고 집행한다.** `DashManager::MorphFromDoeDirectory` 와 `DashDoeConfigManager::saveDoeToCsv` 가 사라지고, 잔여 4곳이 워커화 불요인 근거가 기록으로 남는다.

- 따라서 본 티켓은 **워커화 티켓이 아니라 dead code 정리 + 판정 봉인 티켓**이다. 소유 `processEvents` 0곳이라 W10 1축 DoD(#279)와 무관하고, 분할 그룹(`split-group:215`)에도 넣지 않았다 — #215 의 종결 조건(구현 자식 5건)을 늘리지 않는 **별건 후속**이다.
- **#281 보다 먼저 처리하면 이득이 있다** — `MorphFromDoeDirectory` 가 `MorphingGate` claim 을 쓰므로, 먼저 삭제하면 #281 의 `Claim` → `Reservation` 마이그레이션 대상이 1곳 줄어든다. 늦게 처리하면 #281 이 죽은 코드를 함께 마이그레이션한 뒤 본 티켓이 그걸 지우는 낭비가 생긴다.
