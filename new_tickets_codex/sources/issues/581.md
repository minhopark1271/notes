# #581 Analysis Launcher: Orthogonal Array 의 Level 옵션이 표시되지 않음 (QStackedWidget 경고)

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/581
- Board status: Done
- Labels: ['bugfix', 'refactor']

## 현상
- 앱 시작 시 콘솔에 `QStackedWidget::setCurrentWidget: widget 0x... not contained in stack` 경고 2회
- Analysis Launcher 에서 **Orthogonal Array** 를 골라도 `Level:` 옆에 Level 스핀박스 대신 Constrained function 입력칸이 보인다 → 사용자가 Level 을 바꿀 수 없음

## 원인
- `view/DashAnalysisLauncherWidget.cpp:778,783` 이 스택의 페이지가 아닌 자식 위젯(`levelSpinBox` · `constrainedFuncEdit`)을 `setCurrentWidget` 에 넘긴다
- UI 이관(9c73df3)에서 두 위젯이 `levelPage` · `constrainedFuncPage` 로 감싸진 뒤 호출이 무시되고, 스택은 첫 페이지(`constrainedFuncPage`)에 고정된다

## 작업
- 두 호출을 `ui->levelPage` · `ui->constrainedFuncPage` 로 교체 (2줄, .ui 무수정)

## 확인
- 시작 시 경고 0회
- Orthogonal Array → Level 스핀박스 표시 · 값 변경 반영, 그 외 방식 → Constrained function 입력칸 표시
