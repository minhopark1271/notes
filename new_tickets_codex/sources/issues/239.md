- **상류 결합이 파일명 문자열 5홉이고 둘은 프로세스 밖을 지난다.** `DV-Geometry.source` → `DOE Table.source[]` → 전처리 XML → `model_info.json` → `configs/` 재개방. `Selected Design Variables` 의 **위치가 계약**(index 0 = Condition · 1 = Geometry, `DashDataProcessor.cpp:2829-2840`)이라 순서가 뒤집히면 프리뷰가 조용히 실패한다
