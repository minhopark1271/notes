# #589 Data Upload: 빈 응답 목록이면 다음 결과 파일 탐색

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/589
- Board status: Done
- Labels: ['in-progress', 'bugfix', 'refactor']

첫 결과 파일이 빈 응답 목록 `{}`을 반환해도 `DashResponseInitializer`가 초기화 성공으로 처리합니다. 다음 정상 파일을 탐색하지 않아 응답 목록에 의존하는 후속 샘플도 제외될 수 있습니다.

빈 목록이면 다음 결과 파일을 탐색하고, 모든 목록이 비어 있으면 초기화 실패로 처리합니다. JSON 형식과 정상 응답의 처리 방식은 유지합니다.

모달 주파수는 응답 목록 없이 시점 정보로 처리할 수 있으므로, 목록 초기화 실패만으로 모달 배치를 중단하지 않습니다. 응답 목록이 필요한 Mode Shape는 누락 처리합니다.

완료 기준:

- [x] 첫 파일의 목록이 비어 있어도 다음 정상 파일에서 응답을 초기화한다.
- [x] 모든 목록이 비어 있으면 실패를 반환하고 빈 결과를 성공으로 처리하지 않는다.
- [x] 빈 응답 목록에서도 유효한 모달 주파수를 저장하며, Mode Shape 누락이 다음 주파수 요청을 막지 않는다.
- [x] 재현 테스트와 Level 1 테스트가 통과하고 Release 앱 빌드 오류가 0이다.
- [x] 새 세션에서 변경 범위·시나리오·컨벤션·불필요한 기능·컨셉 이탈을 검토한다.
