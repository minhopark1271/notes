# #645 Project Assets: Add File로 덮어쓴 파일이 Condition 화면에 반영되지 않고 복사 실패 시 기존 등록이 사라진다

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/645
- Board status: Backlog
- Labels: ['bug', 'refactor']

## 현상

- Project Assets의 Add File로 같은 이름의 다른 파일을 덮어쓰면 디스크 파일과 트리 항목은 바뀌지만, Condition Parameter 화면의 부품·하중 목록은 이전 내용을 그대로 보여준다.
- Add File에서 프로젝트 폴더로 복사가 실패하면 원장 등록과 연동 Set 생성이 중간에 끊겨, 기존에 있던 파일의 등록 정보까지 함께 사라질 수 있다.

## 원인

덮어쓰기 뒤 참조 모델 컨텍스트는 다시 읽지만(#617), Condition Parameter 위젯은 그 신호를 받지 않는다. 복사 실패 경로는 실패 이전 상태로 되돌리는 처리가 없다.

## 기대

- 덮어쓴 파일을 참조하는 Condition Parameter 화면이 새 파일 내용으로 갱신된다.
- 복사가 실패하면 기존 파일·원장 항목·Set을 그대로 두고 실패 사유를 알린다.
