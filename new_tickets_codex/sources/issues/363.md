## Goal
Mesh View 도크 제목줄이 현재 렌더 중인 파일명을 띄워 기준 ≠ 렌더 상태가 화면에 드러나고, 렌더 갈래에서 죽은 코드가 사라진다.

## Background
> source: wiki [Project-Manifest-4-Ticket-Slicing](https://github.com/NumeRealWorks/DashOpti_GUI/wiki/Project-Manifest-4-Ticket-Slicing) "PR 상세" G4 절

커서가 두 층으로 갈린 뒤에는 "렌더 중인 파일" 과 "기준모델" 이 다를 수 있다. 사용자가 그 상태를 알 방법이 필요하다 — 렌더는 도크 제목줄, 기준모델은 Load 버튼 활성 상태로 표시한다 (D7). 렌더 갈래의 마지막 PR 이라 갈래에서 확인된 죽은 코드 정리를 여기 붙인다 (S6 — 삭제만 하는 티켓은 맨 뒤로).

## Technical Details

### as-is
- `m_renderDock`(`view/DashMainWindow.cpp:1569`) 제목줄이 렌더 대상을 표시하지 않는다
- 죽은 코드 — include 3 · 함수 4 · 오버로드 1 · 인자 1 (아래 Phase 2 목록)
- `DashMainWindow::updateCheckedPartsGeometry`(`:2598-`)는 인자 `filePath` 를 받아 놓고 컨텍스트는 `activeContext()`(`:2604`)로 얻는다 — 살릴 경우 그 자체가 결함이다

### to-be
- `m_renderDock` 제목줄에 현재 렌더 파일명. `displayedContextChanged` 구독 (선례 `m_leftDock->setWindowTitle(...)` `:3008`·`:3068` — 인자는 각각 `folderName`·`projectName`)
- 죽은 include·함수·오버로드·인자 제거

### not-to-be
- `DashModelingTreeWidget::populate`(`view/DashModelingTreeWidget.cpp:369`) — T11(G5)이 인자를 원장 목록으로 바꿔 되살린다. 지우지 않는다
- 기준모델 표시 UI — Load 버튼 활성 상태가 그 역할이고(D7) 복원 동기화는 T10(G5)의 몫이다
- G3 앞으로 당기기 — 얻는 rename 절감이 1~2건이라 R2 미달
