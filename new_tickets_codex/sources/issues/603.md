# #603 Condition Parameter: Reference File과 Set을 1:1로 연동한다

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/603
- Board status: Done
- Labels: ['feature', 'refactor']

## 목적

Project Assets의 Reference File과 Condition Parameter Set, Analysis Launcher Set을 각각 1:1로 연동한다.

## 범위

- Reference File이 추가되면 같은 이름(점은 밑줄로 치환, 예: `bracket_inp`)의 Condition Set과 Analysis Launcher Set을 자동 생성하고, 그 파일에 직접 pin한다. 파싱을 지원하지 않는 포맷(.dfsxml/.wbpj/.stli)은 Set을 만들지 않는다.
- Condition Parameter·Analysis Launcher의 Add Set·Rename 제거
- Reference File을 삭제하면 두 Set도 삭제되고, 어느 Set을 삭제해도 Reference File과 나머지 Set이 함께 삭제된다. 삭제 전에 확인 창을 띄운다.
- Condition Set 선택을 행 번호가 아니라 이름·setId로 매칭한다.

## 범위 밖

- 기존 프로젝트 변환. 파일과 짝이 없는 기존 Set은 그대로 둔다.
- Launcher 탭의 Reference 표 제거는 #601에서 처리한다.

## 순서

#602(#617) 다음, #601 이전에 진행한다. #601의 Launcher 탭은 Set = 파일을 전제로 만든다.
