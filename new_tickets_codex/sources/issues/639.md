# #639 Analysis Launcher: Target Part 로딩 중 Start를 누르면 빈 target이 저장되고 로드 실패 시 저장값이 지워짐

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/639
- Board status: Backlog
- Labels: ['bug', 'refactor']

## 현상

Analysis Launcher의 Launcher 탭에 들어가 Target Part 콤보가 채워지기 전에 Start를 누르면 `input_files[0].target_component`가 빈 문자열로 저장되어 .inp 케이스가 전부 실패한다. RW 로드가 실패한 상태로 탭에 들어가도 저장돼 있던 target이 빈 값으로 덮어써진다.

## 원인

`DashAnalysisLauncherWidgetLauncher.cpp`의 탭 진입 경로가 Start를 먼저 활성화하고 콤보를 비운 뒤 `co_await`로 부품 목록을 읽으며, 탭 진입마다 `currentText() != saved`이면 저장값을 덮어쓴다.

## 기대

부품 목록을 읽는 동안 Start와 Target Part 콤보를 비활성화하고, 로드가 끝난 뒤 저장값을 반영한다. 로드가 실패하면 저장된 target을 건드리지 않는다.
