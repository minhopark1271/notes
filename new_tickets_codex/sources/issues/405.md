## 대상

`DashXmlParser` 의 FieldStatistics 계열이 저장소 어디에서도 호출되지 않는다.

| 심벌 | 호출자 |
|---|---|
| `extractFieldStatistics` | **0건** |
| `computeFieldStatistics` | `extractFieldStatistics` 뿐 |
| `reduceStd` | `computeFieldStatistics` 뿐 |
| `struct FieldStatistics` | 위 셋 |

즉 `extractFieldStatistics` 에서 시작하는 사슬 전체가 죽어 있다. 헤더 주석은 `reduction="None"` 케이스용(Analyzer_Refactoring_Guide)이라고 적고 있으나, 현재 그 경로로 들어오는 호출자가 없다.

## 왜 지금 올리나

죽은 채로 결함을 하나 안고 있다. `extractFieldStatistics` 에는 가드가 하나도 없어서

```cpp
const XmlValue& sample = *xmlData.dictData[sampleKey];
const TensorData& tensor = sample.dictData[variableName]->tensorData;
```

`const QMap::operator[]` 가 키 없을 때 널 `shared_ptr` 를 돌려주므로 **널 역참조**다. 호출자가 없어 증상이 없을 뿐이다.

고쳐서 살릴지 지울지 결정이 필요하다. 고치는 쪽은 아무도 안 부르는 코드에 가드와 테스트를 붙이는 비용이고, 지우는 쪽은 예정된 기능이 있다면 되살려야 하는 비용이다. 삭제해도 git 이력에 남으므로 복구는 싸다.

## 결정할 것

1. `reduction="None"` 경로가 실제 로드맵에 있나? 있다면 언제, 누가 부르나?
2. 없다면 `FieldStatistics`, `extractFieldStatistics`, `computeFieldStatistics`, `reduceStd` 를 삭제한다.

`reduceStd` 는 #404 수정에서 되살아날 수 있으니 **그 이슈를 먼저 처리한 뒤** 삭제 범위를 정한다.
