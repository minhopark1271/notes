# #563 Geometry Parameter Non-design(Constraints) 영역이 재진입·Set 전환 시 사라진다 — Set 이 JSON constraints 를 쓰지 않고 로더만 읽는 비대칭

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/563
- Board status: Backlog
- Labels: ['bug', 'source:QC']

## 현상
1. Geometry Parameter 에서 Constraints 로 Non-design 영역을 지정하고 Set 을 누른다.
2. 모듈을 나갔다 다시 들어오거나 Set 을 전환하면 Constraints 표가 비어 있고 화면에 Non-design 영역이 보이지 않는다. 핸들과 DV 는 정상 복원된다.
3. 이 상태에서 Set 을 한 번 더 누르면 VTP 의 `AllFixedVolumeIds` 가 빈 배열로 덮어써져, Analysis Launcher 의 DOE-Morphing 도 Non-design 없이 실행된다.

BTA066 프로젝트 확인: `GeometryParameter_BTA066.vtp` 에는 `AllFixedVolumeIds` 64,071 개가 남아 있지만 `GeometryParameter_BTA066.json` 의 `Morphing` 절에는 `handles_vtp`·`radius`·`straight_sided` 만 있고 `constraints` 가 없다.

## 원인
Set 저장 경로가 `Morphing.constraints` 를 JSON 에 쓰지 않는데, 로드 경로는 여전히 그 키를 읽어 표를 복원한다.

- 저장: `viewmodel/DashGeometryParameterPresentationModel.cpp:355-372` — `handles_vtp`·`radius`·`straight_sided`·`DV-Geometry`·`referenceModel` 만 기록
- 로드: 같은 파일 `:447-467` — `morphingObj["constraints"]` 를 읽어 `appendConstraintTable` 호출. 저장하는 곳이 코드베이스에 없다
- VTP 복원: `view/DashGeometryParameterWidget.cpp:2698-2734` `loadHandlesFromVtp` — 핸들만 DeepCopy, `AllFixedVolumeIds` 를 표·`m_constraintSurfaceIds` 로 되돌리는 로직 없음
- 재-Set 시 유실: `controller/DashHandlePickingInteraction.cpp:3042-3059` `GetAllFixedVolumePointIds` 가 빈 `m_constraintSurfaceIds` 로 VTP 를 재작성

회귀: `060d693` (#92, 2026-01-06) 에서 constraints 저장·복원 왕복을 도입했으나, `c4b60ef` ("onsavedesignvariables() 함수 수정완", 2026-03-04 작성, 03-11 dev 반영, PR 없음) 가 저장 함수를 재작성하며 저장 블록만 삭제했다. `fd57024` (W21 PM 이관) 이 비대칭을 그대로 계승했다. `git log -S'morphingSection["constraints"]'` 결과는 추가·삭제 두 건뿐이다.

부수: `m_nonDesignSurfaceIds` 의 유일한 writer `UpdateNonDesignFromUG()` (`:2894`) 는 호출부가 없어 항상 비어 있다. 실질 Non-design 소스는 Constraints 표 하나다. 또 `updateConstraintVisualization` (`DashGeometryParameterWidget.cpp:2772-2795`) 이 Show 상태인 행만 `SetVisibleConstraintIds` 에 넘겨, Hide 상태로 Set 을 누르면 Non-design 이 축소 저장된다.

## 기대
핸들과 같은 분업으로 저장·복원한다.

- JSON `Morphing.constraints`: 이름·그룹 id 만 (표 복원용). id 목록과 Show 상태는 넣지 않는다.
- VTP FieldData: `ConstraintSurfaceCellIds` + `ConstraintGroupIds` 병렬 Int32 배열 (surface 셀 id, 그룹 id 로 JSON 과 조인). `AllFixedVolumeIds` 는 Set 시 셀 id 에서 파생해 그대로 유지 (DOE 소비 경로 불변).
- 로드: JSON 이름 + VTP 그룹 배열 → 그룹별 `appendConstraintTable` → 기존 시각화·`SetVisibleConstraintIds` 사슬로 복원. Set 전환·모델 로드 시 표를 비우고 재적재.
- Show/Hide 는 시각화에만 관여한다. Set 수집은 표 전체 행 대상, `updateConstraintVisualization` 에서 소속 갱신과 표시 갱신을 분리.
- 마이그레이션: JSON·그룹 배열 없이 `AllFixedVolumeIds` 만 있는 레거시 VTP 는 로드 시 참조 모델의 `vtuIds` 로 볼륨 포인트 → surface 셀 역변환 (셀의 모든 포인트가 포함된 셀) 하여 단일 행으로 표에 적재하고, 다음 Set 에서 새 형식으로 영속화한다. 1~3월 구형식 (`constraints[].node_ids`) 은 셀 id 로 그대로 적재. `referenceModel.uuid` 가 현재 모델과 다르면 복원을 건너뛰고 알린다.
- `m_nonDesignSurfaceIds` / `UpdateNonDesignFromUG()` 사문 코드 제거.

**PR #654 에서 `DashFixedRegion` 이 핸들 상태의 fixed 영역 스펙 자리를 맡는다.**

핸들 상태기의 unpinned 영역은 `DashUnpinnedRegion = std::variant<DashControlRegion, DashFixedRegion>` 이고, `DashFixedRegion` 은 그대로 alternative 로 들어간다. `sample()` 은 fixed 영역의 표본을 변위 0 · controls 없는 pinned 항목으로 낸다. 영속은 `Morphing.handles.unpinned[]` 안이며, 구 `constraints[]` 는 더 쓰지 않는다(변환도 하지 않는다 — 구 Set 은 재작성 안내).

따라서 이 이슈는 `DashFixedRegion` 의 alternative(node set 참조 · 라벨 · 그리드 마스크)와 생산지 UI 를 바꾸되, `unpinned[]` 바깥 구조는 건드리지 않는 범위로 잡으면 된다. control 영역의 라벨화도 같은 자리에서 한다.
