# #602 Modeling Tree: 프로젝트 파일 관리 트리(Project Assets)로 전환한다

- URL: https://github.com/NumeRealWorks/DashOpti_GUI/issues/602
- Board status: Done
- Labels: ['feature', 'refactor']

## 목적



Modeling Tree를 프로젝트가 참조·산출하는 파일을 관리하는 "Project Assets" 트리로 바꾼다.



## 범위



- Project Tree 버튼 비활성화, Add File 버튼을 Project Assets 하단으로 이관

- Add File: 분석 입력 파일 선택 → 프로젝트 폴더로 복사 → 파싱 → Reference File 아래에 추가

- 최상위 분류 "Reference File": 파일이 부모, 파싱한 부품이 자식. View·Color·Opacity는 기존과 같다. 파싱을 지원하지 않는 포맷은 부모만 추가하고 View·Color·Opacity를 비활성화한다.

- 최상위 분류 "DOE Table": DOE Sampler가 만든 csv를 부모로 나열한다(자식 없음, View 토글로 CSV 뷰어 표시/숨김).

- Reference File 목록은 프로젝트에 저장하고 다시 열 때 복원한다. 표시는 한 번에 하나만 한다.

- Reference File을 삭제하면 복사된 파일도 지운다.



## 범위 밖



- vtk/stp/prt 로드·프리뷰
