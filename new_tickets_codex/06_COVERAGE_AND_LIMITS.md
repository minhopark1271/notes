## 전체성의 기준

이 문서 묶음에서 ‘전체 목록’은 **2026-10-05 보드 스냅샷 207개와 조사한 핵심 사용자 흐름에서 도출한 유효 요구의 전수 처분**을 뜻한다. 당시 열린 이슈112개가 모두 새 작업 또는 근거 있는 해결/대체 처분으로 연결된다. 아직 발견하지 못한 결함이 없다는 뜻이나 모든 코드를 실행 검증했다는 뜻은 아니다.

닫힌 항목의 `historical` 처분은 이력 보존이다. 완료 티켓을 모두 다시 구현/전수 재현하지 않았다. 반면 열린 항목을 해결됨으로 제외한 경우(#376 등)는 현재 코드 근거를 남겼다. 구현 규모는 PR 하나의 일관된 목적을 기준으로 유연하게 잡았으며 일부 환경/형식 결정은 구현 PR 없이 조사 결론으로 끝날 수 있다.

## 이번 조사에서 확인한 증거의 강도

- **현재 코드 확인**: dev의 구현·호출부·테스트 소스·문서를 읽고 실패 또는 누락 경로를 대조했다. 담당 research 문서와 카드의 파일/행/심벌이 근거다.
- **과거 PR 자료 확인**: 2026-10-05 당시 PR530/651/652/654의 본문·head/base SHA·전체 diff를 저장하고 대조했다. 작성자가 보고한 테스트 통과를 이번 실행 결과로 옮기지 않았다. PR530은 2026-10-07 미병합 CLOSED 확인 이후 현재 실행 작업에서 제외했다.
- **외부 저장소 확인**: Registry/meta의 지정 파일과 blob SHA를 읽었다. provider 머신 내부 SDK·캐시·라이선스는 보지 못했다.
- **구현 제안**: 해결 방식·완료 조건·테스트 계획은 앞으로 수행할 작업이다. 정적 경로로 확인한 위험과 런타임에서 이미 재현한 증상을 구분했다.

## 실제 실행이 필요한 관문

GEO-007, RES-11, UI-01, DEV-02/04/05는 별도 실측 판정이다. Windows 앱, VTK/OCCT 표시, NX·Ansys·Abaqus·fe-safe, 외부 SDK/라이선스, 대용량 fixture가 필요한 시나리오는 이 macOS 조사에서 실행하지 않았다. 특히 GUI thread affinity는 코루틴 표기만으로 입증되지 않으며 실제 trace가 필요하다.

취소는 SDK 내부 함수를 즉시 중단할 수 있다는 약속이 아니다. 중단 불가 구간에서는 후속 제출을 멈추고 결과를 폐기하며 종료까지 수명을 보존하는 계약을 검증해야 한다. UI는 실제 취소 능력을 정확하게 표시해야 한다.

## 문서 품질 검증

`scripts/validate_catalog.py`가 필수 필드·ID·태그·상태·의존 참조/순환·보드 전수 대응·원문 소스 존재·로컬 링크·미병합 PR 중복 집계를 검사한다. 현재 결과는 표준 출력으로 확인한다. [과거 검증 보고](reviews/validation.md)는 조사 당시 스냅샷으로 보존한다. 이 검사는 애플리케이션 테스트가 아니다.

교차검토 지적과 최종 처분은 [리뷰 반영 기록](reviews/REVIEW_RESOLUTIONS.md)에 있다. 미해결 제품 결정·런타임 한계는 숨기지 않고 각 카드의 판정/메모에 유지했다.
