# 도메인 구조도 — 6 도메인 박스 다이어그램 텍스트 전사

> **성격**: 독립 참조 문서. 사내 GUI 구조도(Domain 1\~6 박스 다이어그램)를 텍스트로 옮긴 전사본. 박스별 코드 대조표는 담지 않는다 — 소유·참조 계층은 [204-1-entity-ownership-hierarchy](204-1-entity-ownership-hierarchy.md) 를 본다.
> **관련 문서**: [204-1-entity-ownership-hierarchy](204-1-entity-ownership-hierarchy.md) — 소유·참조 계층(누가 누구를 소유하나) · [192-1-architecture-analysis-mvc-mvvm](192-1-architecture-analysis-mvc-mvvm.md) — 계층 경계 판정 · [End-to-End-User-Flow](End-to-End-User-Flow.md) — 사용자 동선
> **저장소**: [DashOpti_GUI](https://github.com/NumeRealWorks/DashOpti_GUI) · 모듈 — [DashOpti_ReaderWriter](https://github.com/NumeRealWorks/DashOpti_ReaderWriter) · [DashOpti_Morphing](https://github.com/NumeRealWorks/DashOpti_Morphing)
> **Python Extensions**: 2026-09 에 [DashOpti_PythonExtensions](https://github.com/NumeRealWorks/DashOpti_PythonExtensions) 의 브랜치별 6개 프로젝트를 개별 레포(`DashOpti_*`)로 분리했다 — [TopOptPostprocessor](https://github.com/NumeRealWorks/DashOpti_TopOptPostprocessor) · [MCU](https://github.com/NumeRealWorks/DashOpti_MCU) · [AnsysMotion_Writer_Launcher](https://github.com/NumeRealWorks/DashOpti_AnsysMotion_Writer_Launcher) · [AnsysMech_Journal_Launcher](https://github.com/NumeRealWorks/DashOpti_AnsysMech_Journal_Launcher) · [CadNx](https://github.com/NumeRealWorks/DashOpti_CadNx) · [SensitivityAnalysisEngine](https://github.com/NumeRealWorks/DashOpti_SensitivityAnalysisEngine). 각 레포는 `main`/`test`/`deploy` 3-브랜치 구조이고, 신규 확장은 [DashOpti_ExtensionTemplate](https://github.com/NumeRealWorks/DashOpti_ExtensionTemplate) 에서 시작한다.
> **좌표 기준**: 원본에 없이 보탠 박스 2개의 근거는 `feat/reference-model-manifest` @ `32dda58` 실측이다.
> **검증 수준**: 정적 코드 근거만 — 빌드·실행 검증 없음.
> **원본 구조도**: 사내 공유 이미지. 담당자 배정이 함께 그려져 있으나 본 문서는 **박스 이름과 도메인 구획만** 옮기고 담당자 정보는 옮기지 않는다.

## 구조도 텍스트 도식

### 도메인 간 엣지

| 표시 | 원본 라벨 | 방향 |
|---|---|---|
| `(1)` | 경로 설정 | Main Window · DashManager → Domain 1 |
| `(2)` | 렌더링 · 시각화 | Domain 3 → Domain 2 |
| `(3)` | setModel() 바인딩 | Domain 3 → Domain 4 |
| `(4)` | 외부 프로세스 호출 | Domain 4 → Domain 5 |
| `(5)` | 앱 전체 상태 참조 | DashManager ↔ Domain 1 · 3 · 4 (원본의 점선 루프) |

`Gizmo Plane`·`DOE Config Manager` 의 왼쪽 화살표는 원본 그대로다. 코드상 방향은 둘 다 C++ → DLL.
